
# 01 - Function with No Arguments and No Return Value

## 📌 Description
This C program demonstrates a user-defined function
that takes no arguments and does not return any value.

The function is called from the main() function
to display a welcome message on the screen.

## 🎯 Objective
- Understand the concept of user-defined functions.
- Learn function declaration, definition, and calling.
- Understand the `void` return type.
- Learn how to create and use a simple function.

## 💻 Source Code
The program uses a function named `displayMessage()`.

### Function Syntax
```c
void functionName(void)
{
    // Statements
}
```

## ⚙️ How It Works
1. The program starts execution from `main()`.
2. The function `displayMessage()` is declared.
3. The function is called inside `main()`.
4. Control transfers to the function definition.
5. The function displays a message using `printf()`.
6. Control returns to `main()`.

## 📤 Sample Output
```text
Welcome to C Programming!
Learning Functions in C.
```

## 🧠 Concepts Used
- User-defined functions
- Function declaration
- Function definition
- Function calling
- `void` return type
- `printf()` function

## 📊 Function Characteristics

| Property | Description |
|---|---|
| Function Name | displayMessage |
| Arguments | No arguments |
| Return Type | void |
| Return Value | No value |
| Function Call | displayMessage(); |

## ⏱️ Time Complexity
O(1) - Constant time.

## 📚 Learning Outcome
After completing this program, you will understand
how to create, declare, define, and call a simple
user-defined function in C.
