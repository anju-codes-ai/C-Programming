
# 02 - Function with Arguments and No Return Value

## 📌 Description
This C program demonstrates a user-defined function
that accepts arguments but does not return any value.

The program takes two numbers from the user and
passes them to a function named `addNumbers()`.
The function calculates and displays their sum.

## 🎯 Objective
- Understand functions with arguments.
- Learn how to pass values to a function.
- Understand the `void` return type.
- Practise function declaration, definition, and calling.

## 💻 Function Syntax

```c
void functionName(data_type parameter1, data_type parameter2)
{
    // Statements
}
```

## ⚙️ How It Works
1. The program starts execution from `main()`.
2. Two numbers are entered by the user.
3. The function `addNumbers()` is called with both numbers.
4. The values are received by parameters `a` and `b`.
5. The function calculates their sum.
6. The result is displayed using `printf()`.

## 📤 Sample Output

```text
Enter first number: 10
Enter second number: 20
Sum = 30
```

## 🧠 Concepts Used
- User-defined functions
- Function arguments
- Function parameters
- Function declaration
- Function definition
- Function calling
- `void` return type
- `scanf()` and `printf()`

## 📊 Function Characteristics

| Property | Description |
|---|---|
| Function Name | addNumbers |
| Arguments | Two integers |
| Return Type | void |
| Return Value | No value |
| Parameters | int a, int b |

## ⏱️ Time Complexity
O(1) - Constant time.

## 📚 Learning Outcome
After completing this program, you will understand
how to pass arguments to a user-defined function
and perform operations inside that function.
