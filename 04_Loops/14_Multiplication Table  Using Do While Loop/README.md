# Multiplication Table Using do-while Loop

## Description
This program prints the multiplication table of 5 using a do-while loop in C.

## Concept Used
- do-while Loop
- Multiplication Operator
- Increment Operator
- Loop Condition

## Output
```text id="p7k2qa"
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

## Learning Outcome
Learned how to generate a multiplication table using a do-while loop in C.
