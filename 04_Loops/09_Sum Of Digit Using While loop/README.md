# Sum of Digits Using while Loop

## Description
This program calculates the sum of all digits of a given number using a while loop in C.

## Concept Used
- while Loop
- Modulus Operator (%)
- Division Operator (/)
- Addition Operator (+)

## Output
```text id="p8w2qa"
Sum of Digits = 15
```

## Learning Outcome
Learned how to extract individual digits and calculate their sum using a while loop in C.
