
# Find Power of a Number Using do-while Loop

## Description
This C program calculates the power of a number using a do-while loop. It takes a base and an exponent from the user and multiplies the base repeatedly.

## Example
Base = 2
Exponent = 5
Result = 32

## Concepts Used
- do-while Loop
- Integer Variables
- User Input
- Multiplication

## Sample Output
```text
Enter the base: 2
Enter the exponent: 5
Power = 32
```

## Learning Outcome
Understand how to use a do-while loop to calculate the power of a number.
