# Reverse a Number Using while Loop

## Description
This program reverses a given number using a while loop in C.

## Concept Used
- while Loop
- Modulus Operator (%)
- Division Operator (/)
- Arithmetic Operations

## Output
```text id="a9k3wp"
Reverse Number = 54321
```
