# Sum of Natural Numbers Using do-while Loop

## Description
This program calculates the sum of the first 10 natural numbers using a do-while loop in C.

## Concept Used
- do-while Loop
- Addition Operator
- Increment Operator
- Loop Condition

## Output
```text id="k7p2qa"
Sum = 55
```

## Learning Outcome
Learned how to calculate the sum of natural numbers using a do-while loop in C.
