# Relational Operators in C

## Description
This program demonstrates the use of relational operators in C to compare two numbers.

## Operators Used
- `==` Equal to
- `!=` Not equal to
- `>` Greater than
- `<` Less than
- `>=` Greater than or equal to
- `<=` Less than or equal to

## Output
```text
a == b : 0
a != b : 1
a > b  : 1
a < b  : 0
a >= b : 1
a <= b : 0
```

## Learning Outcome
Learned how to compare two values using relational operators in C. In C, `1` represents true and `0` represents false.
