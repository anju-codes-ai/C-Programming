# 09 - Take Age as Input

## 📌 About
This is a basic C program that accepts the user's age and displays it on the screen.

## 🎯 Objective
To understand how to take an integer input from the user using the `scanf()` function.

## 💻 Output
```text
Enter your age: 18
Your age is 18
```

## 📚 Concepts Learned
- Integer data type (`int`)
- Variable declaration
- `scanf()` function
- `printf()` function
- Integer format specifier (`%d`)
- Address operator (`&`)

## 🚀 Learning Outcome
Learned how to accept an integer value from the user and display it.
