# 05 - Print Float Number

## 📌 About
This is a basic C program that stores and displays a decimal number using a float variable.

## 🎯 Objective
To understand the `float` data type and display decimal values using the `printf()` function.

## 💻 Output
```text
Price is 99.50
```

## 📚 Concepts Learned
- Float data type (`float`)
- Variable declaration and initialization
- Format specifier (`%f`)
- Precision specifier (`%.2f`)
- `printf()` function

## 🚀 Learning Outcome
Learned how to store and display decimal numbers in C programming.
