# 03 - Print Age

## 📌 About
This is a basic C program that stores and displays age using an integer variable.

## 🎯 Objective
To understand how to declare an integer variable and display its value using `printf()`.

## 💻 Output
```text
My age is 18
```

## 📚 Concepts Learned
- Integer data type (`int`)
- Variable declaration and initialization
- Format specifier (`%d`)
- `printf()` function

## 🚀 Learning Outcome
Learned how to store an integer value in a variable and display it on the screen.
