# 10 - Take City as Input

## 📌 About
This is a basic C program that accepts the user's city name and displays it on the screen.

## 🎯 Objective
To understand how to accept string input from the user using the `scanf()` function.

## 💻 Output
```text
Enter your city: Mohali
Your city is Mohali
```

## 📚 Concepts Learned
- Character array (`char`)
- `scanf()` function
- `printf()` function
- String format specifier (`%s`)
- User input

## 🚀 Learning Outcome
Learned how to accept and display a city name entered by the user.
