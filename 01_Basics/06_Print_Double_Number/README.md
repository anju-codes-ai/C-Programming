# 06 - Print Double Number

## 📌 About
This is a basic C program that stores and displays a decimal value using the double data type.

## 🎯 Objective
To understand the `double` data type and learn how to display decimal values in C programming.

## 💻 Output
```text
Distance is 123.456789
```

## 📚 Concepts Learned
- Double data type (`double`)
- Variable declaration and initialization
- Format specifier (`%lf`)
- `printf()` function

## 🚀 Learning Outcome
Learned how to store and display decimal values using the double data type.
