# 08 - Take Name as Input

## 📌 About
This is a basic C program that takes a user's name as input and displays it on the screen.

## 🎯 Objective
To understand how to accept user input using the `scanf()` function.

## 💻 Output
```text
Enter your name: Anju
Your name is Anju
```

## 📚 Concepts Learned
- Character array (`char`)
- `scanf()` function
- `printf()` function
- String format specifier (`%s`)
- User input

## 🚀 Learning Outcome
Learned how to accept and display a name entered by the user.
