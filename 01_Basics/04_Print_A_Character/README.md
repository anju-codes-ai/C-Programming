# 04 - Print a Character

## 📌 About
This is a basic C program that stores and displays a single character using a variable.

## 🎯 Objective
To understand the `char` data type and display a character using the `printf()` function.

## 💻 Output
```text
My grade is A
```

## 📚 Concepts Learned
- Character data type (`char`)
- Variable declaration and initialization
- Format specifier (`%c`)
- `printf()` function

## 🚀 Learning Outcome
Learned how to store and display a single character in C programming.
