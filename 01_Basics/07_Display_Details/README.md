# 07 - Display Your Details

## 📌 About
This program displays personal details using different variables and data types.

## 🎯 Objective
To understand how multiple variables of different data types can be used in a single C program.

## 💻 Output
```text
Name: Anju
Age: 18
Grade: A
Marks: 85.5
```

## 📚 Concepts Learned
- Character array (`char`)
- Integer data type (`int`)
- Float data type (`float`)
- Character data type (`char`)
- Variable declaration and initialization
- `printf()` function
- Newline character (`\n`)

## 🚀 Learning Outcome
Learned how to store and display different types of information using variables.
