# 02 - Print Your Name

## 📌 About
This is a basic C program that displays a name on the screen.

## 🎯 Objective
To understand how to use the `printf()` function to display text in C programming.

## 💻 Output
```text
My name is Anju
```

## 📚 Concepts Learned
- `printf()` function
- Displaying text on the screen
- Basic C program structure

## 🚀 Learning Outcome
Learned how to display a personal name using the `printf()` function.
