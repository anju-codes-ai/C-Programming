# 01 - C Programming Basics

## 📌 About
This folder contains my first 10 basic C programming practice programs. These programs are designed to build a strong foundation in C programming.

## 🎯 Objective
To understand the fundamentals of C programming, including variables, data types, output statements, and user input.

## 📚 Topics Covered
- Basic structure of a C program
- `printf()` function
- `scanf()` function
- Variables and data types
- Integer (`int`)
- Float (`float`)
- Double (`double`)
- Character (`char`)
- Character arrays (Strings)
- Format specifiers
