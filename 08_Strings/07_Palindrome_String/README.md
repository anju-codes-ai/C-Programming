
# 07 - Check Palindrome String

## Description
This C program checks whether a given string
is a palindrome or not.

A palindrome is a word that reads the same
forward and backward.

## Concepts Used
- Strings
- Character Arrays
- For Loop
- If-Else Statement
- strlen() Function
- Flag Variable

## How It Works
1. Declare a character array.
2. Read a string from the user.
3. Remove the newline character.
4. Calculate the string length.
5. Compare characters from opposite positions.
6. If all characters match, it is a palindrome.
7. Otherwise, it is not a palindrome.

## Sample Output
```text
Enter a string: madam
The string is a palindrome.
```

## Learning Outcome
Understand how to check palindrome strings
using loops and character comparison.

## Time Complexity
O(n)
