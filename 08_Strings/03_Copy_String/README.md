
# 03 - Copy One String into Another

## Description
This C program copies the contents of one
string into another using the strcpy() function.

## Concepts Used
- Strings
- Character Arrays
- strcpy() Function
- fgets()
- string.h Header File

## How It Works
1. Declare two character arrays.
2. Read a string from the user.
3. Remove the newline character.
4. Use strcpy() to copy the first string
   into the second string.
5. Display both strings.

## Sample Output
```text
Enter a string: Hello World
Original string: Hello World
Copied string: Hello World
```

## Learning Outcome
Understand how to copy one string into
another using the built-in strcpy() function.

## Function Used
strcpy() - Copies one string into another.
