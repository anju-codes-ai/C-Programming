
# 02 - Find Length of a String

## Description
This C program calculates the total number
of characters present in a string using strlen().

## Concepts Used
- Strings
- Character Arrays
- strlen() Function
- fgets()
- string.h Header File

## How It Works
1. Declare a character array.
2. Read a string using fgets().
3. Remove the newline character if present.
4. Use strlen() to calculate the string length.
5. Display the total number of characters.

## Sample Output
```text
Enter a string: Hello World
Length of string = 11
```

## Learning Outcome
Understand how to calculate the length
of a string using the built-in strlen() function.

## Function Used
strlen() - Returns the number of characters
in a string, excluding the null character.
