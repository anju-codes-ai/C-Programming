
# 09 - Count Words in a String

## Description
This C program counts the total number of
words present in a given string.

## Concepts Used
- Strings
- Character Arrays
- For Loop
- If-Else Statement
- Flag Variable
- isspace() Function

## How It Works
1. Declare a character array.
2. Read a sentence using fgets().
3. Traverse each character using a for loop.
4. Check whether the character is whitespace.
5. Detect the beginning of each new word.
6. Increase the word counter.
7. Display the total number of words.

## Sample Output
```text
Enter a string: C programming is interesting

Total words = 4
```

## Learning Outcome
Understand how to count words in a sentence
using loops and character checking.

## Function Used
isspace() - Checks whether a character
is a whitespace character.

## Time Complexity
O(n)
