
# 04 - Concatenate Two Strings

## Description
This C program joins two strings into
a single string using the strcat() function.

## Concepts Used
- Strings
- Character Arrays
- strcat() Function
- fgets()
- string.h Header File

## How It Works
1. Declare two character arrays.
2. Read the first string.
3. Read the second string.
4. Remove newline characters from both strings.
5. Use strcat() to append the second string
   to the first string.
6. Display the concatenated string.

## Sample Output
```text
Enter first string: Hello
Enter second string: World

Concatenated string: HelloWorld
```

## Learning Outcome
Understand how to join two strings using
the built-in strcat() function.

## Function Used
strcat() - Appends one string to another.
