
# 08 - Count Vowels and Consonants in a String

## Description
This C program counts the total number of
vowels and consonants present in a string.

## Concepts Used
- Strings
- Character Arrays
- For Loop
- If-Else Statement
- Character Checking
- tolower() Function

## How It Works
1. Declare a character array.
2. Read a string using fgets().
3. Traverse each character using a for loop.
4. Convert each character to lowercase.
5. Check whether the character is an alphabet.
6. Identify vowels and consonants.
7. Display their total counts.

## Sample Output
```text
Enter a string: Hello World
Vowels = 3
Consonants = 7
```

## Learning Outcome
Learn how to identify and count vowels
and consonants using character checking.

## Functions Used
- tolower() - Converts a character into lowercase.
- fgets() - Reads a string from the user.

## Time Complexity
O(n)
