
# 10 - Convert String into Uppercase and Lowercase

## Description
This C program converts a given string
into uppercase and lowercase characters.

## Concepts Used
- Strings
- Character Arrays
- For Loop
- toupper() Function
- tolower() Function
- ctype.h Header File

## How It Works
1. Declare three character arrays.
2. Read a string using fgets().
3. Traverse each character using a for loop.
4. Convert each character into uppercase.
5. Convert each character into lowercase.
6. Store the converted characters in separate arrays.
7. Display both results.

## Sample Output
```text
Enter a string: Hello World

Uppercase string: HELLO WORLD
Lowercase string: hello world
```

## Learning Outcome
Learn how to change the case of characters
using built-in character conversion functions.

## Functions Used
- toupper() - Converts a character to uppercase.
- tolower() - Converts a character to lowercase.

## Time Complexity
O(n)
