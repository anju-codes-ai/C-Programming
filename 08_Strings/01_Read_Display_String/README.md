
# 01 - Read and Display a String

## Description
This C program accepts a string from the user
and displays the entered string on the screen.

## Concepts Used
- Character Array
- Strings
- fgets()
- printf()
- String Input and Output

## How It Works
1. Declare a character array.
2. Ask the user to enter a string.
3. Read the string using fgets().
4. Display the entered string using printf().

## Sample Output
```text
Enter a string: Hello World
Entered string: Hello World
```

## Learning Outcome
Learn how to read and display strings in C
using character arrays and fgets().
