
# 06 - Reverse a String

## Description
This C program reverses a given string
by swapping characters from opposite positions.

## Concepts Used
- Strings
- Character Arrays
- For Loop
- strlen() Function
- Temporary Variable
- Swapping Characters

## How It Works
1. Declare a character array.
2. Read a string using fgets().
3. Remove the newline character.
4. Calculate the string length using strlen().
5. Swap characters from the beginning and end.
6. Continue until the middle of the string.
7. Display the reversed string.

## Sample Output
```text
Enter a string: Hello World
Reversed string: dlroW olleH
```

## Learning Outcome
Learn how to reverse a string using loops
and character swapping.

## Time Complexity
O(n)
