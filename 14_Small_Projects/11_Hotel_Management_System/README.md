# Hotel Management System in C

## Project Overview
The Hotel Management System is a menu-driven console application developed using the C programming language.

It simulates basic hotel operations, including room booking, guest record management, room availability checking, and checkout.

The application uses structures and binary file handling to store booking information.

## Features
- Book hotel rooms
- Generate booking IDs
- Display all bookings
- Search bookings by ID
- Check available rooms
- Calculate room bills
- Complete guest checkout
- Store records permanently

## Technologies Used
- Programming Language: C
- Compiler: GCC
- Storage: Binary File Handling

## How to Compile and Run

Compile:

```bash
gcc main.c -o hotel
```

Run on Windows:

```bash
hotel.exe
```

Run on Linux/macOS:

```bash
./hotel
```
