# ATM Simulation System in C

## Project Overview
The ATM Simulation System is a console-based application developed using the C programming language. It demonstrates basic ATM operations, account management, and file handling.

The application allows users to create an account, log in, check their balance, deposit money, withdraw money, change their PIN, and view transaction history.

## Features
- Account creation
- Account number and PIN-based login
- Balance inquiry
- Money deposit
- Money withdrawal
- PIN modification
- Transaction history
- Persistent account storage using file handling

## Technologies Used
- Language: C
- Compiler: GCC
- Concepts: Structures, Functions, Pointers, Switch Statements, Loops, File Handling

## How to Run

Compile the program:

```bash
gcc main.c -o atm
```

Run on Windows:

```bash
atm.exe
```

Run on Linux/macOS:

```bash
./atm
```

## Concepts Practiced
1. Structures for account information
2. Functions for modular programming
3. Pointers for modifying account data
4. Switch statements for menu navigation
5. Binary files for persistent account storage
6. Text files for transaction history

This project strengthens understanding of file handling, structures, functions, pointers, and menu-driven programming in C.
