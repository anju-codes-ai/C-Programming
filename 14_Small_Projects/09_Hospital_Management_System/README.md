# Hospital Management System in C

## Project Overview
The Hospital Management System is a menu-driven console application developed using the C programming language.

It provides basic patient record management functionality, including adding, displaying, searching, updating, and deleting patient records.

The application uses structures to organize patient information and binary file handling to store records.

## Features
- Add new patient records
- Display all patient records
- Search patients using their ID
- Update patient information
- Delete patient records
- Store consultation fee information
- Persistent storage using binary files

## Technologies Used
- Programming Language: C
- Compiler: GCC
- Storage: Binary File Handling

## How to Compile and Run

Compile:

```bash
gcc main.c -o hospital
```

Run on Windows:

```bash
hospital.exe
```

Run on Linux/macOS:

```bash
./hospital
```
