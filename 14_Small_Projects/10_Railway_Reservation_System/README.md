# Railway Reservation System in C

## Project Overview
The Railway Reservation System is a menu-driven console application developed using the C programming language.

It simulates basic railway ticket booking operations, including ticket reservation, booking search, cancellation, and seat availability.

The project uses structures and binary file handling to manage passenger booking records.

## Features
- Book railway tickets
- Generate unique PNR numbers
- Display all reservations
- Search bookings using PNR
- Cancel reservations
- Check available seats
- Calculate ticket fare
- Store booking records permanently

## Technologies Used
- Programming Language: C
- Compiler: GCC
- Storage: Binary File Handling

## How to Compile and Run

Compile:

```bash
gcc main.c -o railway
```

Run on Windows:

```bash
railway.exe
```

Run on Linux/macOS:

```bash
./railway
```
