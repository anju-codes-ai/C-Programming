
# 03 - Average of Array Elements

## Description
This C program calculates the average of all
elements stored in an array.

## Concepts Used
- Arrays
- For Loop
- User Input (scanf)
- Sum Calculation
- Type Casting
- Floating Point Numbers

## How It Works
1. Declare an integer array.
2. Ask the user to enter the number of elements.
3. Read array elements using a for loop.
4. Calculate the sum of all elements.
5. Divide the sum by the total number of elements.
6. Display the average.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
10 20 30 40 50

Average of array elements = 30.00
```

## Learning Outcome
Learn how to calculate the average of array
elements using loops and type casting in C.
