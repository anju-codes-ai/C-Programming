
# 10 - Sort Array in Descending Order

## Description
This C program sorts array elements in
descending order using the Bubble Sort algorithm.

## Concepts Used
- Arrays
- Nested For Loops
- If Statement
- Temporary Variable
- Swapping Elements
- Bubble Sort Algorithm

## How It Works
1. Declare an integer array.
2. Read the number of elements.
3. Input all array elements.
4. Compare adjacent elements.
5. Swap them if the first element is smaller.
6. Repeat the process until the array is sorted.
7. Display the sorted array.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
10 50 20 40 30

Array in descending order:
50 40 30 20 10
```

## Learning Outcome
Learn how to arrange array elements in
decreasing order using Bubble Sort.

## Time Complexity
O(n²)
