
# 07 - Linear Search in an Array

## Description
This C program searches for a given element
in an array using the Linear Search technique.

## Concepts Used
- Arrays
- For Loop
- If Statement
- Break Statement
- Searching Algorithm
- Flag Variable

## How It Works
1. Declare an integer array.
2. Read the number of elements.
3. Input all array elements.
4. Ask the user for the element to search.
5. Compare the search element with each array element.
6. If a match is found, display its position.
7. If no match is found, display "Element not found".

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
10 20 30 40 50
Enter element to search: 30

Element found at position 3
```

## Learning Outcome
Understand how Linear Search works and
how to find an element in an array.

## Time Complexity
Best Case: O(1)
Worst Case: O(n)
