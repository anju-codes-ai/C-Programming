
# 05 - Find Smallest Element in an Array

## Description
This C program finds the smallest element
from the given array.

## Concepts Used
- Arrays
- For Loop
- If Statement
- Comparison Operator
- User Input (scanf)

## How It Works
1. Declare an integer array.
2. Read the number of elements.
3. Input all array elements.
4. Assume the first element is the smallest.
5. Compare all remaining elements.
6. Update the smallest value whenever a
   smaller element is found.
7. Display the smallest element.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
45 12 67 23 34

Smallest element = 12
```

## Learning Outcome
Learn how to find the minimum value in
an array using loops and conditional statements.
