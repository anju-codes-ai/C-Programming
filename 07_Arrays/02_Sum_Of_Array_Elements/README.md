
# 02 - Sum of Array Elements

## Description
This C program calculates the sum of all
elements stored in an array.

## Concepts Used
- Arrays
- For Loop
- User Input (scanf)
- Sum Calculation

## How It Works
1. Declare an integer array.
2. Ask the user to enter the number of elements.
3. Read array elements using a for loop.
4. Add each element to the sum variable.
5. Display the total sum.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
10 20 30 40 50

Sum of array elements = 150
```

## Learning Outcome
Learn how to access array elements and
calculate their total using a loop.
