
# 08 - Reverse an Array

## Description
This C program reverses the order of elements
in an array using a temporary variable.

## Concepts Used
- Arrays
- For Loop
- Temporary Variable
- Swapping Elements

## How It Works
1. Declare an integer array.
2. Read the number of elements.
3. Input all array elements.
4. Use a loop to swap the first and last elements.
5. Continue swapping elements towards the middle.
6. Display the reversed array.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
10 20 30 40 50

Reversed array:
50 40 30 20 10
```

## Learning Outcome
Learn how to reverse an array by swapping
elements from opposite positions.

## Time Complexity
O(n)
