
# 01 - Read and Display Array Elements

## Description
This C program reads elements from the user
and stores them in an array. It then displays
all the entered elements using a loop.

## Concepts Used
- Arrays
- For Loop
- User Input (scanf)
- Output (printf)

## How It Works
1. Declare an integer array.
2. Ask the user for the number of elements.
3. Read elements using a for loop.
4. Display all elements using another for loop.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
10 20 30 40 50

Array elements are:
10 20 30 40 50
```

## Learning Outcome
Learn how to declare, initialize, access,
and display array elements in C.
