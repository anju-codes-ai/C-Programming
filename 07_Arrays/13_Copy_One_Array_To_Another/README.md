
# 13 - Copy One Array into Another

## Description
This C program copies all elements of one
array into another array.

## Concepts Used
- Arrays
- For Loop
- Array Indexing
- Assignment Operator

## How It Works
1. Declare two integer arrays.
2. Read the number of elements.
3. Input elements into the first array.
4. Copy each element into the second array.
5. Display both arrays.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
10 20 30 40 50

Elements of first array:
10 20 30 40 50

Elements of copied array:
10 20 30 40 50
```

## Learning Outcome
Understand how to copy elements from one
array to another using a loop.

## Time Complexity
O(n)
