
# 15 - Remove Duplicate Elements from an Array

## Description
This C program removes duplicate elements
from an array and displays only unique elements.

## Concepts Used
- Arrays
- Nested For Loops
- If Statement
- Array Indexing
- Element Shifting

## How It Works
1. Declare an integer array.
2. Read the number of elements.
3. Input all array elements.
4. Compare each element with the remaining elements.
5. If a duplicate is found, shift the remaining elements left.
6. Decrease the array size.
7. Display the array without duplicates.

## Sample Output
```text
Enter number of elements: 7
Enter array elements:
10 20 10 30 20 40 30

Array after removing duplicates:
10 20 30 40
```

## Learning Outcome
Understand how to identify and remove duplicate
elements using nested loops and array shifting.

## Time Complexity
O(n²)
