
# 12 - Count Positive, Negative and Zero Elements

## Description
This C program counts positive, negative,
and zero values present in an array.

## Concepts Used
- Arrays
- For Loop
- If-Else-If Statement
- Comparison Operators
- Counter Variables

## How It Works
1. Declare an integer array.
2. Initialize three counters to zero.
3. Read the number of elements.
4. Input array elements using a loop.
5. Check whether each element is positive,
   negative, or zero.
6. Increase the corresponding counter.
7. Display all three counts.

## Sample Output
```text
Enter number of elements: 7
Enter array elements:
10 -5 0 20 -8 0 15

Positive elements = 3
Negative elements = 2
Zero elements = 2
```

## Learning Outcome
Learn how to classify and count positive,
negative, and zero values using arrays.

## Time Complexity
O(n)
