
# 04 - Find Largest Element in an Array

## Description
This C program finds the largest element
from the given array.

## Concepts Used
- Arrays
- For Loop
- If Statement
- Comparison Operator
- User Input (scanf)

## How It Works
1. Declare an integer array.
2. Read the number of elements.
3. Input all array elements.
4. Assume the first element is the largest.
5. Compare every remaining element.
6. Update the largest value whenever a
   greater element is found.
7. Display the largest element.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
12 45 23 67 34

Largest element = 67
```

## Learning Outcome
Learn how to find the maximum value in
an array using loops and conditional statements.
