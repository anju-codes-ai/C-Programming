
# 14 - Merge Two Arrays

## Description
This C program combines two arrays into
a single array.

## Concepts Used
- Arrays
- For Loop
- Array Indexing
- Multiple Arrays

## How It Works
1. Declare two input arrays and one merged array.
2. Read the number of elements in both arrays.
3. Input elements into the first array.
4. Input elements into the second array.
5. Copy the first array into the merged array.
6. Copy the second array after the first array elements.
7. Display the merged array.

## Sample Output
```text
Enter number of elements in first array: 3
Enter first array elements:
10 20 30

Enter number of elements in second array: 3
Enter second array elements:
40 50 60

Merged array:
10 20 30 40 50 60
```

## Learning Outcome
Learn how to combine two arrays into
one array using loops and array indexing.

## Time Complexity
O(n1 + n2)
