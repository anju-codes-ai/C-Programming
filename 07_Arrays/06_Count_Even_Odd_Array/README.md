
# 06 - Count Even and Odd Elements in an Array

## Description
This C program counts the total number of
even and odd elements present in an array.

## Concepts Used
- Arrays
- For Loop
- If-Else Statement
- Modulus Operator (%)
- Counter Variables

## How It Works
1. Declare an integer array.
2. Initialize even and odd counters to zero.
3. Read the number of array elements.
4. Input elements using a for loop.
5. Check whether each element is divisible by 2.
6. Increase the even or odd counter.
7. Display both counts.

## Sample Output
```text
Enter number of elements: 6
Enter array elements:
10 15 20 25 30 35

Even elements = 3
Odd elements = 3
```

## Learning Outcome
Learn how to classify and count even and odd
numbers using arrays and conditional statements.
