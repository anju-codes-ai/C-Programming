
# 11 - Find Second Largest Element in an Array

## Description
This C program finds the second largest
distinct element present in an array.

## Concepts Used
- Arrays
- For Loop
- If-Else Statement
- Comparison Operators
- Variable Updating

## How It Works
1. Declare an integer array.
2. Read the number of elements.
3. Input all array elements.
4. Initialize the largest and second largest values.
5. Compare each element with the largest value.
6. Update the largest and second largest values.
7. Display the second largest distinct element.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
10 50 30 40 20

Second largest element = 40
```

## Learning Outcome
Learn how to find the second largest distinct
value in an array using comparisons.

## Time Complexity
O(n)
