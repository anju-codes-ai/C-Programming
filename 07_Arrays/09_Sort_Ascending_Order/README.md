
# 09 - Sort Array in Ascending Order

## Description
This C program sorts array elements in
ascending order using the Bubble Sort algorithm.

## Concepts Used
- Arrays
- Nested For Loops
- If Statement
- Temporary Variable
- Swapping Elements
- Bubble Sort Algorithm

## How It Works
1. Declare an integer array.
2. Read the number of elements.
3. Input all array elements.
4. Compare adjacent elements.
5. Swap them if the first element is greater.
6. Repeat the process until the array is sorted.
7. Display the sorted array.

## Sample Output
```text
Enter number of elements: 5
Enter array elements:
50 20 40 10 30

Array in ascending order:
10 20 30 40 50
```

## Learning Outcome
Understand how to arrange array elements
in increasing order using Bubble Sort.

## Time Complexity
Best Case: O(n) with an optimized version
Average Case: O(n²)
Worst Case: O(n²)
