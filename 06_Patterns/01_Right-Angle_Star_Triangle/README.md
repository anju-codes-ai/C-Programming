
# Right-Angled Star Triangle in C

## Description
This C program prints a right-angled triangle pattern using stars (*).

The program uses nested for loops to print stars in increasing order.

## Sample Output
```text
*
* *
* * *
* * * *
* * * * *
```

## Concepts Used
- Nested for Loop
- printf() Function
- Pattern Printing
- Row and Column Logic

## Learning Outcome
Understand how nested loops work and how to create a basic star pattern in C.
