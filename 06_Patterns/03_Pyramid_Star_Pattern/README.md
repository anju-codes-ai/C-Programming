
# Pyramid Star Pattern in C

## Description
This C program prints a centered pyramid pattern using stars (*).

It uses nested for loops to print spaces and stars in each row.

## Sample Output
```text
    *
   ***
  *****
 *******
*********
```

## Concepts Used
- Nested for Loop
- Space Management
- Pattern Printing
- Row and Column Logic

## Learning Outcome
Understand how to use spaces and nested loops to create a centered pyramid pattern in C.
