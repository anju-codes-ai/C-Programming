
# Inverted Pyramid Star Pattern in C

## Description
This C program prints an inverted centered pyramid pattern using stars (*).

The program uses nested for loops to decrease the number of stars and increase spaces in each row.

## Sample Output
```text id="p9e8jb"
*********
 *******
  *****
   ***
    *
```

## Concepts Used
- Nested for Loop
- Space Management
- Decrement
- Pattern Printing

## Learning Outcome
Understand how to print an inverted pyramid by controlling spaces and stars using nested loops in C.
