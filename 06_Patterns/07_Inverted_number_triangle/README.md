
# Inverted Number Triangle in C

## Description
This C program prints an inverted number triangle pattern.

Each row displays numbers starting from 1, while the number of elements decreases in every row.

## Sample Output
```text id="m8k2wp"
1 2 3 4 5
1 2 3 4
1 2 3
1 2
1
```

## Concepts Used
- Nested for Loop
- Decrement
- Integer Variables
- Pattern Printing

## Learning Outcome
Understand how to create an inverted number triangle using nested loops in C.
