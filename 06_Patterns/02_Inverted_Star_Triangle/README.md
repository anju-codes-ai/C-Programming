
# Inverted Star Triangle in C

## Description
This C program prints an inverted right-angled triangle pattern using stars (*).

The number of stars decreases in each row using nested for loops.

## Sample Output
```text
* * * * *
* * * *
* * *
* *
*
```

## Concepts Used
- Nested for Loop
- Decrement
- printf() Function
- Pattern Printing

## Learning Outcome
Understand how to print an inverted star triangle using nested loops in C.
