
# Alphabet Triangle Pattern in C

## Description
This C program prints an alphabet triangle pattern using uppercase English letters.

Each row starts from A and prints letters in increasing order.

## Sample Output
```text id="b5m8qx"
A
A B
A B C
A B C D
A B C D E
```

## Concepts Used
- Nested for Loop
- Character Data
- ASCII Values
- printf() Function
- Pattern Printing

## Learning Outcome
Understand how to print alphabet patterns using nested loops and character values in C.
