
# Pascal's Triangle in C

## Description
This program prints Pascal's Triangle using numbers.
Each number is calculated using the previous value in the row.

## Sample Output
```text
     1
    1 1
   1 2 1
  1 3 3 1
 1 4 6 4 1
```

## Concepts Used
- Nested for loops
- Number calculation
- Variables
- Mathematical operations
- Pattern printing

## Logic
1. The outer loop controls the rows.
2. Spaces are printed to align the triangle.
3. Each row starts with the value 1.
4. The next number is calculated using the previous value.
5. The process continues until all rows are printed.

## Learning Outcome
Understand nested loops and number calculations
while creating Pascal's Triangle in C.
