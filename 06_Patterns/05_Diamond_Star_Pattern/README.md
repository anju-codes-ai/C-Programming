
# Diamond Star Pattern in C

## Description
This C program prints a diamond-shaped pattern using stars (*).

It uses nested for loops to print the upper and lower halves of the diamond.

## Sample Output
```text
    *
   ***
  *****
 *******
*********
 *******
  *****
   ***
    *
```

## Concepts Used
- Nested for Loop
- Space Management
- Increment and Decrement
- Pattern Printing

## Learning Outcome
Understand how to combine two pyramid patterns to create a diamond shape using C programming.
