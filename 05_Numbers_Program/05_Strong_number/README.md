
# Strong Number in C

## Description
This C program checks whether a given number is a Strong Number or not.

A Strong Number is a number whose sum of the factorials of its digits is equal to the original number.

## Example
Number = 145

1! + 4! + 5! = 1 + 24 + 120 = 145

Therefore, 145 is a Strong Number.

## Concepts Used
- while Loop
- for Loop
- Factorial
- Modulus Operator
- Integer Division
- if-else Statement

## Sample Output
```text
Enter a number: 145
145 is a Strong Number.
```

## Learning Outcome
Understand how to calculate factorials of individual digits and check a Strong Number using C programming.
