
# Palindrome Number in C

## Description
This C program checks whether a given number is a palindrome or not.

A palindrome number remains the same when its digits are reversed.

## Example
Original Number = 121
Reversed Number = 121

Therefore, 121 is a Palindrome Number.

## Concepts Used
- while Loop
- if-else Statement
- Modulus Operator
- Integer Division
- Arithmetic Operations

## Sample Output
```text
Enter a number: 121
121 is a Palindrome Number.
```

## Learning Outcome
Understand how to reverse a number and check whether it is a palindrome using C programming.
