
# Prime Number in C

## Description
This C program checks whether a given number is a prime number or not.

A prime number is a number greater than 1 that has exactly two factors: 1 and itself.

## Example
Number = 7

Factors = 1, 7

Therefore, 7 is a Prime Number.

## Concepts Used
- for Loop
- if-else Statement
- Modulus Operator
- Counter Variable
- Arithmetic Operations

## Sample Output
```text
Enter a number: 7
7 is a Prime Number.
```

## Learning Outcome
Understand how to check prime numbers using loops and the modulus operator in C.
