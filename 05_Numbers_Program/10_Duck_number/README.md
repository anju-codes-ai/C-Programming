
# Duck Number in C

## Description
This C program checks whether a given number is a Duck Number or not.

A Duck Number is a positive number that contains at least one zero, excluding leading zeros.

## Example
Number = 1023

Digits = 1, 0, 2, 3

Since the number contains zero, it is a Duck Number.

## Concepts Used
- while Loop
- if-else Statement
- break Statement
- Modulus Operator
- Integer Division

## Sample Output
```text
Enter a number: 1023
1023 is a Duck Number.
```

## Learning Outcome
Understand how to extract digits and check whether a number contains zero using C programming.
