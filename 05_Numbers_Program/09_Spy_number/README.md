
# Spy Number in C

## Description
This C program checks whether a given number is a Spy Number or not.

A Spy Number is a number in which the sum of its digits is equal to the product of its digits.

## Example
Number = 123

Sum = 1 + 2 + 3 = 6

Product = 1 × 2 × 3 = 6

Therefore, 123 is a Spy Number.

## Concepts Used
- while Loop
- if-else Statement
- Modulus Operator
- Integer Division
- Sum and Product of Digits

## Sample Output
```text
Enter a number: 123
123 is a Spy Number.
```

## Learning Outcome
Understand how to calculate the sum and product of digits and check whether they are equal.
