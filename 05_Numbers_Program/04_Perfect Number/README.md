
# Perfect Number in C

## Description
This C program checks whether a given number is a perfect number or not.

A perfect number is a positive number that is equal to the sum of its proper factors, excluding itself.

## Example
Number = 28

Factors = 1, 2, 4, 7, 14

Sum = 1 + 2 + 4 + 7 + 14 = 28

Therefore, 28 is a Perfect Number.

## Concepts Used
- for Loop
- if-else Statement
- Modulus Operator
- Sum Variable
- Arithmetic Operations

## Sample Output
```text
Enter a number: 28
28 is a Perfect Number.
```

## Learning Outcome
Understand how to find the factors of a number and check whether their sum equals the original number.
