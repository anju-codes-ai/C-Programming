
# Harshad Number in C

## Description
This C program checks whether a given number is a Harshad Number or not.

A Harshad Number is a number that is divisible by the sum of its digits.

## Example
Number = 18

Sum of digits = 1 + 8 = 9

18 ÷ 9 = 2

Therefore, 18 is a Harshad Number.

## Concepts Used
- while Loop
- if-else Statement
- Modulus Operator
- Integer Division
- Sum of Digits

## Sample Output
```text
Enter a number: 18
18 is a Harshad Number.
```

## Learning Outcome
Understand how to calculate the sum of digits and check divisibility in C programming.
