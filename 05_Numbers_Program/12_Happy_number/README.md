
# Happy Number in C

## Description
This C program checks whether a given positive number is a Happy Number or not.

A Happy Number is a number that eventually becomes 1 when repeatedly replaced by the sum of the squares of its digits.

## Example
Number = 19

1² + 9² = 82

8² + 2² = 68

6² + 8² = 100

1² + 0² + 0² = 1

Therefore, 19 is a Happy Number.

## Concepts Used
- while Loop
- Nested while Loop
- if-else Statement
- Modulus Operator
- Integer Division
- Sum of Squares

## Sample Output
```text id="2j5q9m"
Enter a number: 19
19 is a Happy Number.
```

## Learning Outcome
Understand how to extract digits, calculate their squares, and check a Happy Number using C programming.
