
# Armstrong Number in C

## Description
This C program checks whether a given three-digit number is an Armstrong number or not.

An Armstrong number is a number whose sum of cubes of its digits is equal to the original number.

## Example
153 = 1³ + 5³ + 3³
153 = 1 + 125 + 27
153 = 153

Therefore, 153 is an Armstrong Number.

## Concepts Used
- while Loop
- if-else Statement
- Modulus Operator
- Integer Division
- Arithmetic Operations

## Sample Output
```text
Enter a number: 153
153 is an Armstrong Number.
```

## Learning Outcome
Understand how to extract digits and check an Armstrong number using C programming.
