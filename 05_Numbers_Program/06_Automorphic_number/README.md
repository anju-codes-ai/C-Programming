
# Automorphic Number in C

## Description
This C program checks whether a number is an Automorphic Number or not.

An Automorphic Number is a number whose square ends with the same digits as the original number.

## Example
Number = 25

Square = 25 × 25 = 625

Since 625 ends with 25, it is an Automorphic Number.

## Concepts Used
- while Loop
- if Statement
- Modulus Operator
- Integer Division
- Square of a Number

## Sample Output
```text
Enter a number: 25
25 is an Automorphic Number.
```

## Learning Outcome
Understand how to calculate the square of a number and compare its ending digits with the original number.
