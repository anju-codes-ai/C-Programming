
# Abundant Number in C

## Description
This C program checks whether a given number is an Abundant Number or not.

An Abundant Number is a positive number whose proper factors have a sum greater than the original number.

## Example
Number = 12

Proper Factors = 1, 2, 3, 4, 6

Sum = 1 + 2 + 3 + 4 + 6 = 16

Since 16 is greater than 12, it is an Abundant Number.

## Concepts Used
- for Loop
- if-else Statement
- Modulus Operator
- Sum of Factors
- Arithmetic Operations

## Sample Output
```text id="9yft7j"
Enter a number: 12
12 is an Abundant Number.
```

## Learning Outcome
Understand how to find the proper factors of a number and check whether their sum is greater than the original number.
